# 2026-08-12 收银项目调研

## 任务
林子轩父亲在荷兰开 Btea5 奶茶店，已有 Windows 触屏硬件，需要类似麦当劳/KFC 的自助点餐收银机软件。
核心需求：点单 → 订单 → 后厨通知(KDS) → 小票打印 → 欧洲信用卡/iDEAL 收款 → Windows 运行。
已询问最需要解决的问题与开源项目推荐。

## 调研结果

### 自助点餐 Kiosk 开源项目（最匹配需求）
1. **Open-Kiosk-App** (qqq-tech) — React + Vite + Tailwind + Firebase + 热敏打印，支持多币种/多语言/语音搜索/离线，**Windows 直接跑**，门槛低
2. **simOrder** (simOrderS) — 树莓派 + Django + Apache + ESC/POS 打印机，轻量POS
3. **BurgerScreen / SelfOrderBurgerKiosk** (raultejada24) — 西语，触摸+支付+持久化
4. **ViewTouch** — 1986 年老牌 GPLv3，Linux + X Window + Monetra 信用卡

### KDS 厨房显示系统
1. **URY Mosaic** — 基于 ERPNext 的完整 POS+KDS+报表，10+ 门店运行 10 个月
2. **OpenKDS** (benclementt) — 简单独立 KDS
3. **posso.co.uk** 系列 — 英式，色彩编码订单
4. **TanStack POS** — React 19 + tRPC + PostgreSQL + Docker，现代感强

### 完整 POS 框架（可二次开发）
- Floreant POS（Java，经典）
- Chromis POS
- uniCenta oPOS（30万+ 零售商）
- URY（POS+KDS+报表+库存完整套件）
- TanStack POS（React 19 新栈）

### 欧洲支付（重点）
- **Mollie** ⭐ 首选：荷兰本土公司，10分钟接入，支持 iDEAL（70% 荷兰人用）+ Visa/MC/Amex/Bancontact/Klarna/Apple Pay，**有 Python/Node/PHP SDK**，按笔收费，€0.25 起/笔
- Stripe：国际通用，欧洲全境，但 iDEAL 需用 Stripe 单独申请
- Adyen：荷兰巨头，门槛高，适合大企业

## 关键判断
- **最大难点**：不是软件本身，而是 **Mollie/Stripe 账号注册 + iDEAL/卡支付接入 + 触屏端卡机/PIN 终端硬件配合**
- 父亲自营店建议：**Open-Kiosk-App（前端）+ 后厨加一台显示器看 KDS + Mollie 收款 + ESC/POS 热敏小票打印机**
- 林子轩本人没编程基础 → 优先找"开箱即用 + Windows 直接跑"的方案，避免从 0 写
