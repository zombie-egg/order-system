🏆 最匹配的 5 个开源项目

① Open-Kiosk-App ⭐首推

📎 github.com/qqq-tech/Open-Kiosk-App
专门给零售/咖啡店/快餐厅设计的开源 Kiosk，一键打包成 Windows 应用。最贴近 Btea5 需求。
  • React + Vite + Tailwind 现代界面
  • Firebase 实时数据库（云端+本地）
  • 热敏打印机集成（ESP32 UART）
  • 多语言 + 多币种（欧元EUR直接支持）
  • 语音搜索 + 离线运行
  • 销售报表 + CSV 导出
Windows 原生 离线可用 现代UI 需二次开发支付

② TanStack POS

📎 github.com/kadekdodikwirawan/tan-pos
现代感最强的开源 POS 平台，自带 KDS 厨房显示。最适合"专业感"。
  • React 19 + TanStack Start + tRPC
  • 三个界面：Manager/Serve/Kitchen
  • 实时同步订单，毫秒级推送
  • Docker 一键部署
  • 桌面/平板/TV 全兼容
KDS 完整 Docker 部署 现代感最强 英文文档

③ URY（完整生态）

📎 github.com/SoftServedWeb-com/ury
基于 ERPNext 的完整开源餐厅管理系统，已在 10+ 门店稳定运行 10 个月。POS + KDS + 库存 + 报表一站式。
  • POS 收银 + MOSAIC KDS
  • P&L 报表 + 库存管理
  • 多厨房 + 打印机路由
  • 支持堂食/外卖/外送
  • 桌台管理 + 预订
企业级 POS+KDS全 部署复杂 需ERPNext

④ simOrder（极简）

📎 github.com/simOrderS/simOrder
最轻量级，Django + Apache + 热敏打印机。适合"最小可用"的方案。
  • 树莓派即可跑（也可装 PC）
  • ESC/POS 打印机直连
  • 多用户权限管理
  • 销售报表
极轻量 小白友好 界面朴素 无KDS

⑤ Floreant POS（老牌经典）

📎 github.com/cnqvnet/floreantpos · 官网
Java 桌面 POS 经典项目，分支 Chromis POS / uniCenta oPOS。商业级稳定。
  • Java 跨平台（Windows 完美）
  • 30 万+ 零售商使用
  • 支持 KDS 接入
  • 开源 + 商业生态成熟
稳定 成熟生态 Java 老技术 UI 不够现代

💰 欧洲支付方案（最大难点）

⚠️ 父亲真正的卡点：欧洲支付 ≠ 微信支付

  • 荷兰人 70% 用 iDEAL（银行直连转账，手续费低）
  • 信用卡 Visa/MC/Amex 占比其次
  • 年轻人爱用 Apple Pay / Bancontact
  • 没有现成的"扫一扫"二维码（那是亚洲玩法）

✅ 强烈推荐：Mollie（荷兰本土支付）

  1. 为什么选 Mollie：荷兰本土公司，10 分钟接入，专门给中小企业做的，开发者体验最好 —— mollie.com ↗ / 开发者文档 ↗
  2. 支持方式：iDEAL、Visa、MasterCard、Amex、Bancontact、Klarna、Apple Pay、PayPal 一站搞定
  3. 技术栈：官方 Python/Node/PHP/Java/.NET SDK，你用 Python Flask 已经能对接
  4. 费用：iDEAL €0.25/笔，信用卡 1.8% + €0.25（消费卡），无月费
  5. 注册：需荷兰银行账户 + KVK（商会号），如果用你父亲的身份开，资料齐全即可
  6. 备选：Stripe ↗（国际通用，欧洲全境，但 iDEAL 需单独申请）

🎯 我给的 3 个方案

方案 A：最快上线（推荐 ★★★）

Open-Kiosk-App + Mollie + KDS 后加

  1. 把 Open-Kiosk-App 部署到现有 Windows 触屏上
  2. 菜单图直接放上去，Firebase 配置商品库
  3. 买一台 ESC/POS 58mm 热敏打印机（USB 口，€20-50）
  4. 对接 Mollie 卡支付（iDEAL + Visa/MC）
  5. 后厨加一台旧电脑/平板做 KDS（显示订单号）
  6. 预计 2-4 周可以上线

方案 B：完整专业（适合长期经营）

TanStack POS 或 URY + Mollie + 完整硬件

  1. Docker 部署完整 POS 系统
  2. 前端触屏点餐 + 后厨 KDS + 后台报表一站
  3. Mollie 收款 + 财务报表自动生成
  4. 需要你会一点 Docker / 编程基础
  5. 预计 4-8 周

方案 C：自己写（如果你想练手）

Flask/Vue + 上述任一开源 + Mollie SDK

  1. 你已经有 Flask 图片生成的底子
  2. 前端用 Vue3 + Element Plus 写一个触屏点餐界面
  3. 后端 Flask 接 MySQL + Mollie API
  4. 复用 Open-Kiosk 的热敏打印模块
  5. 工作量最大（8-12 周），但定制性最强

🚨 目前最大的问题（也是最容易踩坑的）

最大难点：支付 + 硬件 + 软件的"三方对接"

  1. ① Mollie/Stripe 账号：
    需要荷兰本地银行账号 + KVK 商号注册；以你爸 Btea5 的名义开。开通 iDEAL 最快，信用卡需要 PCI-DSS 合规材料。
  2. ② PIN Pad（刷卡机）硬件：
    触屏只是"下单机"，收卡需要外接 Verifone / Ingenico 等 PCI 认证的 PIN Pad（荷兰常用 Worldline / CCV）。这块要单独买硬件，不是软件能解决的。
  3. ③ 热敏打印机驱动：
    Windows 装 ESC/POS 通用驱动就行（推荐 Epson TM-T20 或 Star TSP143），USB 接电脑。
  4. ④ KDS 后厨屏幕：
    需要另一台旧电脑/平板 + 一个简单的 KDS 页面，这个是聊天记录里你爸明确要的"通知服务员"功能。
  5. ⑤ 父子沟通 + 实际菜单：
    Btea5 的菜单图（我看屏幕上有大概 18 款饮品）、价格、规格（杯型/糖度/加料），需要你爸拍下来给你，AI 才能自动生成菜单数据。
